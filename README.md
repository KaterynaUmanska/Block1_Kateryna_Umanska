# Система агрегації статистики за закупівлями (Java Core)

Консольна багатопотокова програма на Java для потокового парсингу JSON-файлів із купівельними заявками, обчислення статистики за вказаним атрибутом та генерації відсортованого XML-звіту.

---

## 1. Опис основних сутностей

Проєкт побудований на принципах об'єктно-орієнтованого програмування та демонструє зв'язок між сутностями:

* **`PurchaseRequisition` (Заявка)** — основна сутність, що містить інформацію про закупівлю.
    * Поля: `id` (Long), `material` (Material — вкладений об'єкт), `quantity` (Double), `status` (Status — Enum: `DRAFT`, `APPROVED`, `REJECTED`), `tags` (String — текстові теги через кому).
* **`Material` (Матеріал)** — другорядна сутність (зв'язок **Many-to-One** із заявкою).
    * Поля: `id` (Long), `name` (String), `unit` (Unit — Enum: `KG`, `PCS`, `METERS`, `LITERS`), `description` (String).

---

## 2. Приклад вхідного JSON-файлу

Кожен файл містить масив об'єктів-заявок:

```json
[
  {
    "id": 100001,
    "material": {
      "id": 42,
      "name": "Material_15",
      "unit": "PCS",
      "description": "Деталь для збірки"
    },
    "quantity": 45.5,
    "status": "APPROVED",
    "tags": "IT, Hardware"
  }
]
